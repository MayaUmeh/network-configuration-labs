Network Configuration Labs

Network design and configuration coursework for the Operating Systems and Networks module at the University of Hertfordshire. Coursework mark: 87%.

What I built
RIP routing: a multi router network using RIP so routers learn routes to every subnet automatically
DHCP: a DHCP server so hosts receive IP addresses automatically from the right pool
VLANs: VLAN segmentation across switches to separate network traffic
Linux: an Ubuntu virtual machine set up and configured from scratch
How I tested it
ping and tracert between hosts on different subnets and VLANs
Checked routing tables with show ip route to confirm RIP had learned every route
Confirmed hosts received DHCP addresses from the correct pool
